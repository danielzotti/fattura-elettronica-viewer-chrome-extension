## 🇮🇹 Descrizione Dettagliata per il Chrome Web Store (Italiano)

*Nota per la pubblicazione: copiare il testo sottostante nel campo "Descrizione dettagliata" della Developer Dashboard.*

```text
Visualizza qualsiasi fattura elettronica italiana (XML standard o file firmato digitalmente .p7m) in un formato grafico chiaro, moderno e professionale. Esporta direttamente in formato PDF A4 pronto per la stampa o l'archiviazione contabile.

Nessun dato viene mai inviato a server esterni: l'elaborazione avviene al 100% in locale nel tuo browser per garantire la massima privacy fiscale e conformità GDPR.


CARATTERISTICHE PRINCIPALI

• Visualizzazione Grafica Immediata: trasforma istantaneamente file XML e P7M complessi in documenti ordinati, leggibili e divisi in sezioni intuitive.
• Esportazione PDF & Stampa A4: genera con un click documenti PDF vettoriali impaginati per fogli A4 oppure avvia la stampa nativa ottimizzata.
• Schede Cedente & Cessionario: pannelli dedicati per Fornitore e Cliente con pulsanti di copia rapida per Partita IVA, Codice Fiscale, PEC e Codice Destinatario SDI.
• Decodifica Automatica Codici SDI: traduce in chiaro tutti i codici dell'Agenzia delle Entrate (tipi documento TD01..TD28, regimi fiscali RF01..RF19, modalità pagamento MP01..MP23, nature IVA ed esigibilità IVA / Split Payment).
• Tabella Righe & Ricerca Tempo Reale: esplora le righe di dettaglio con prezzi unitari, sconti, aliquote IVA e barra di ricerca istantanea per descrizione articolo o codice.
• KPI & Riepilogo Totali: indicatori visivi per Totale Documento, Imponibile, IVA, Ritenute d'acconto, Casse Previdenziali e Bollo virtuale.
• Gestione Allegati: individua e permette di scaricare con un click tutti i file allegati incorporati nel file XML (es. PDF riepilogativi, relazioni tecniche).
• Supporto Dark Mode & Light Mode: interfaccia moderna con passaggio automatico o manuale tra tema chiaro e tema scuro ad alto contrasto.


COME SI USA

1. Apri l'estensione cliccando sull'icona nella barra degli strumenti di Chrome.
2. Trascina (Drag & Drop) un file .xml o .p7m, oppure incolla direttamente il testo XML.
3. In alternativa, fai click col tasto destro su un link a un file fattura o su un testo XML selezionato e scegli "Apri con Fattura Elettronica Viewer".
4. Consulta i dettagli o clicca su "Esporta PDF" / "Stampa" per salvare il documento.


PRIVACY E SICUREZZA DEI DATI

• 100% Elaborazione Locale: il parsing del file XML e la generazione del PDF avvengono interamente all'interno del tuo browser.
• Zero Trasferimento Dati: nessun file, dato fiscale o informazione aziendale viene mai inviato o salvato su server remoti.
• Funziona Offline: puoi visualizzare ed esportare le tue fatture anche in assenza di connessione internet.


PERMESSI RICHIESTI

• "storage": necessario esclusivamente per salvare in locale le preferenze dell'interfaccia (es. tema Chiaro/Scuro) e trasferire temporaneamente la fattura dal menu al visualizzatore.
• "contextMenus": consente di aprire file XML o testi selezionati tramite il menu del tasto destro.
• "tabs": consente di aprire la schermata del visualizzatore grafico in una nuova scheda del browser.


SUPPORTO & FEEDBACK

Progetto open source: hai trovato un bug o vuoi suggerire una funzionalità?
• Repository GitHub: https://github.com/danielzotti/fattura-elettronica-viewer-chrome-extension
• Versione Web standalone: https://fattura-elettronica-viewer.zotti.dev
```

## 🇬🇧 Detailed Store Description (English)

*Useful if you enable multi-language listing or English as fallback.*

```text
View Italian electronic invoices (standard XML and digitally signed .p7m files) in a clean, modern, and readable graphic format. Export directly to print-ready A4 PDF documents with a single click.

100% private and client-side: all processing happens locally inside your browser. No files or fiscal data are ever uploaded to any external server.


KEY FEATURES

• Instant Visual Rendering: convert raw FatturaPA XML and P7M files into clear, well-structured documents.
• A4 PDF Export & Print: generate high-quality vector PDF files formatted for A4 printing or archive.
• Supplier & Customer Cards: dedicated sections for Seller (Cedente/Prestatore) and Buyer (Cessionario/Committente) with one-click copy buttons for VAT Number, Tax Code, PEC Email, and SDI Recipient Code.
• Automatic SDI Code Decoding: human-friendly translation of Italian Revenue Agency codes (Document Types TD01..TD28, Tax Regimes RF01..RF19, Payment Methods MP01..MP23, VAT Exemption natures, Split Payment).
• Itemized Details & Live Search: searchable goods and services table with quantities, unit prices, discounts, and VAT rates.
• Totals & Tax Summary: visual summary cards for Total Invoice Amount, Taxable Base, Total VAT, Withholding Taxes, Welfare Funds, and Virtual Stamp Duty.
• Embedded Attachments: detect and download files embedded inside XML invoices (e.g. original PDFs, timesheets).
• Dark & Light Mode: elegant interface tailored for low-light or daytime work.


HOW TO USE

1. Click the extension icon in your Chrome toolbar.
2. Drag & drop any .xml or .p7m invoice file, or paste raw XML content.
3. Alternatively, right-click on any XML link or selected text and choose "Open with Fattura Elettronica Viewer".
4. Review your invoice or click "Export PDF" / "Print".


PRIVACY & DATA PROTECTION

• 100% Local Processing: XML parsing and PDF generation take place strictly on your computer.
• Zero Data Tracking: no personal data, invoices, or accounting details are collected or transmitted.
• Offline Ready: works seamlessly without an internet connection.


PERMISSIONS

• "storage": used solely to store local UI preferences (Dark/Light mode) and transfer invoice data to the viewer tab.
• "contextMenus": allows opening XML invoice files or selected text via right-click context menu.
• "tabs": allows opening the viewer interface in a new browser tab.


SUPPORT & FEEDBACK

• Open Source Repository: https://github.com/danielzotti/fattura-elettronica-viewer-chrome-extension
• Standalone Web App: https://fattura-elettronica-viewer.zotti.dev
```

The content script only checks for invoice-specific XML root tags (<FatturaElettronica>) to display a discreet floating button allowing 1-click rendering in the visual viewer. No browsing history, web traffic, or personal data is ever collected, modified, or transmitted.`
